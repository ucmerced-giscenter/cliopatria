About this project

Cliopatria brings historical political boundaries into a map that can be explored one year at a time. This interface presents Aligned Cliopatria v1.1, prepared by the GIS Center and Geospatial Services, UC Merced University Library.

The current aligned release contains 52,044 features in 333 panel years, from 3400 BCE to 1497 CE. These are historical snapshots. A panel does not establish the exact start or end date of a polity.

From historical maps to research data

The original Cliopatria project derived historical entities from maps by Andrew Tollefson. The aligned UC Merced release adjusts coastlines and shared borders, corrects labels and geometry, and generalizes boundaries for practical use. The interface is being developed to support public exploration and research downloads.

Each feature represents a polity, leader, group, army, or event in one panel year. Some region polygons intentionally have no name. Source colors are preserved, with a gray fallback where no color is provided.

Interpretation and limitations

The publisher describes shared-topology generalization to 3 km and source maps with a resolution of about 7 km per pixel. These boundaries should not be read as precise modern borders. Modern basemaps provide geographic orientation and may not match historical coastlines.

The release documents 22 inherited overlaps larger than 1,000 km². Small features may differ in area after generalization; from 1003 onward, islands below 1,000 km² retain their source geometry. Map tiles add display generalization at distant zoom levels. Downloads use the hosted feature geometry.

Coverage after 1497 CE is not included in this aligned release. Earlier project notes ending at 1000 CE describe an older state. This project remains in development; save the version, access date, and files used in your research.
