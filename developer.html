Developer documentation

The app is plain HTML, CSS, and JavaScript with locally vendored MapLibre GL JS 5.6.1 and PMTiles 4.3.0. Static per-year tiles provide display geometry. Anonymous ArcGIS queries provide search and attributes; ArcGIS prepares download files. No application backend or runtime build step is required.

Service endpoints

Feature service metadata · Layer 0 metadata · Local display manifest

Append /0/query to the service URL for queries and /createReplica for asynchronous exports. Use outSR=4326 for geographic GeoJSON and replicaSR=4326 for exports. Numeric Year filters support BCE; the live service currently has no timeInfo.

Field dictionary

FieldTypeMeaning
OBJECTIDOIDRelease-specific record ID; may be renumbered.
YearSmall integerPanel year. Negative is BCE; no zero; snapshots are not validity intervals.
AreaSqKMSingle precisionPublisher-calculated geodesic area in km².
NameStringEntity name. Some region names are intentionally blank.
ColorStringSource 0xRRGGBB color, normalized to #RRGGBB in tiles; null fallback #82939A.
TypeStringPOLITY, LEADER, GROUP, ARMY, EVENT, or missing.
WikipediaStringArticle title; converted to an encoded Wikipedia link.

Shape__Area and Shape__Length are service system fields, not substitutes for AreaSqKM. Dedicated alternate-name and region fields are absent.

Sample queries

Count the 3400 BCE panel · Get that panel as GeoJSON

For a range, use Year >= 1000 AND Year <= 1497. For search, use UPPER(Name) LIKE '%ROMAN%'. Escape apostrophes as doubled apostrophes and validate numeric IDs/years. Use form-encoded POST requests for long filters.

The service advertises a 2,000-record query limit. Paginate attribute queries with a stable order, or query IDs. The app uses 25-row search pages and requests no geometry for search results. This limit is not a full-extraction file limit.

Exports and hosting

Filtered exports use layerQueries with queryOption: 'useFilter', useGeometry: true, and the numeric/ID predicate. Full exports omit layerQueries. For an ordinary extent, count intersecting IDs, then send its envelope in native Web Mercator coordinates with inSR=3857. Keep replicaSR=4326 for the output. The spatial filter selects whole polygons without clipping. Use syncModel=none, async=true, and returnAttachments=false. Poll the returned status URL and link directly to the completed file.

See Esri's Create Replica reference. A permanent ArcGIS content item or visitor login is not required by the tested public extraction route.

PMTiles hosting needs byte-range responses (206) with correct Content-Range. Separate tile hosting also needs CORS. Do not gzip whole PMTiles files at the HTTP layer. See PMTiles hosting documentation. For local testing, open index.html with Live Server. The website requires no build step or application backend.

Match the tile manifest and full feature service to the same release. Rebuild after source revisions, especially OBJECTID renumbering. This folder contains the runnable website; data preparation scripts and review reports are maintained separately.

Antimeridian-crossing views use deduplicated ID filters, reduced to exact consecutive-ID ranges and short IN lists. If necessary, the app prepares numbered parts; all parts together contain the selection. If the extent includes every feature in the period, its time predicate is sufficient. A WGS84 filter envelope returned an empty KMZ in validation; native Web Mercator coordinates fixed this, including a 35,741-feature regional export.
